# godot-mcp v0.1.0

The first early-development release of godot-mcp: a Godot 4 editor addon that
connects AI coding assistants to your live project over MCP.

## Highlights

- Manage the bundled MCP host from the **Godot MCP** editor panel.
- Set up **OpenCode**, **Claude Code**, and **Codex** from **Integrations**.
- Inspect and edit scenes, nodes, resources, project settings, and input actions.
- Batch scene edits into a single editor undo step.
- Validate unsaved scenes and run a separate game session with logs and screenshots.

## Install

Use **GodotEnv** with the release ZIP, or extract
`godot-mcp-addon-v0.1.0.zip` into your project root. Enable **Godot MCP** under
**Project Settings → Plugins**, then install your client integration from the
**Godot MCP** panel.

See the [installation guide](https://github.com/davidherring123/godot-mcp#installation).
GitHub's automatically generated source archives do not include host binaries.

## Downloads

- `godot-mcp-addon-v0.1.0.zip`: all supported platforms; recommended for GodotEnv
  and manual installation.
- Platform-specific archives: macOS arm64/x86_64, Linux x86_64/arm64, and Windows x86_64.
- `SHA256SUMS`: archive checksums.

## Known limitations

- Early-development prerelease; APIs and workflows may change.
- Host binaries are not code-signed or notarized.
- Keep the project open in Godot while using MCP tools.
- Screenshots require a windowed runtime session.
- Batch previews and rollback have domain-specific limits; see the
  [reference guide](https://github.com/davidherring123/godot-mcp/blob/v0.1.0/docs/REFERENCE.md).
